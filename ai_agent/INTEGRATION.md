# CrowdVision AI Agent — Integration Guide

## 1. Architectural Relationship

The AI Crowd Management Agent operates as an **independent, decoupled intelligence layer**. It consumes structured analytical outputs generated by the main CrowdVision vision pipeline (OpenCV person detection, YOLOv8/v11, ByteTrack tracking, and short-term density forecasting) and translates them into actionable risk assessments, predictive explanations, prioritized recommendations, and automated alerts.

---

## 2. Non-Blocking Integration Rule

> **CRITICAL REQUIREMENT:**
> The computer vision pipeline must **NEVER** wait synchronously for agent responses. Analytics snapshots should be dispatched in the background via asynchronous workers (or fire-and-forget background tasks) so camera frame processing latency remains strictly dictated by OpenCV/YOLO inference rates (30–60 FPS).

## 3. Step-by-Step Integration

### Step 1: Register Venue Zones at Event Startup

Before streaming analytics, register the venue topology and zone configurations.

```python
import httpx

AGENT_URL = "http://localhost:8100"
API_KEY = "YOUR_CONFIGURED_SECRET_KEY"

async def register_event_venue():
    payload = {
        "event_id": "concert_2026_05_12",
        "event_name": "Summer Music Festival 2026",
```

### Step 2: Stream Analytical Batches from Vision Pipeline

Every 2–5 seconds, publish the aggregated tracking metrics for each zone.

```python
import uuid
from datetime import datetime, timezone
import httpx

async def send_crowd_analytics_batch(zone_snapshots: list[dict]):
    """
    Called periodically from ByteTrack / density computation loop.
    Dispatches analytics asynchronously without blocking OpenCV frame pipeline.
    """
    payload = {
        "data": [
            {
                "event_id": "concert_2026_05_12",
                "venue_id": "metropolis_arena",
                "zone_id": z["zone_id"],
                "camera_id": z.get("camera_id"),
                "timestamp": datetime.now(timezone.utc).isoformat(),
                "people_count": z["tracked_person_count"],
                "current_occupancy": z["current_occupancy_ratio"],  # e.g. 0.78
                "estimated_density": z.get("people_per_sqm"),       # e.g. 2.6
                "inflow_rate": z.get("inflow_per_minute"),          # e.g. 18.5
                "outflow_rate": z.get("outflow_per_minute"),        # e.g. 6.2
                "movement_speed": z.get("mean_velocity_mps"),       # e.g. 0.85
                "movement_direction": z.get("dominant_direction"),  # "INWARD", "MIXED", etc.
                "predicted_occupancy": z.get("projected_occupancy_5m"),
                "forecast_horizon_seconds": 300,
                "forecast_confidence": z.get("forecast_confidence", 0.85),
                "message_id": str(uuid.uuid4())
            }
            for z in zone_snapshots
        ]
    }

    try:
        async with httpx.AsyncClient(timeout=2.0) as client:
            response = await client.post(
                f"{AGENT_URL}/api/v1/agent/analyze",
                json=payload,
                headers={"X-API-Key": API_KEY}
            )
            result = response.json()
            # Handle immediate alerts or recommendations if returned in response
            return result
    except Exception as exc:
        # Non-blocking error handling: log and proceed
        print(f"Warning: AI Agent telemetry delivery failed: {exc}")
```

### Step 3: Real-Time WebSocket Streaming for Dashboard / UI

Connect client dashboards to the WebSocket stream to receive instant alerts and risk updates:

```javascript
// Browser or Electron Dashboard Client
const eventId = "concert_2026_05_12";
const socket = new WebSocket(`ws://localhost:8100/ws/${eventId}`);

socket.onopen = () => {
    console.log("Connected to live CrowdVision AI Agent stream");
    // Heartbeat ping every 25 seconds
    setInterval(() => socket.send("ping"), 25000);
};

socket.onmessage = (event) => {
    const msg = JSON.parse(event.data);
    switch (msg.type) {
        case "alert":
            console.warn("NEW CROWD ALERT:", msg.payload);
            displayAlertBanner(msg.payload);
            break;
        case "risk_change":
            console.log(`Risk changed in ${msg.payload.zone_name}: ${msg.payload.new_risk}`);
            updateHeatmapZoneColor(msg.payload.zone_id, msg.payload.new_risk);
            break;
        case "recommendation":
            console.info("NEW RECOMMENDATION:", msg.payload);
            appendRecommendationCard(msg.payload);
            break;
    }
};
```
